# Last Call at the Lagrange

A casual, pixel-art management sim about a dive bar on a shabby space station. Early days: this is a scene test, with a crowd of pixel people walking around one deck, to check performance on a real iPhone.

Change the crowd size and watch the readout. Tap the floor to place or remove a crate, and people route around it.

```sh
npm ci
npm run dev -- --host
```
