# Last Call at the Lagrange

A casual, pixel-art management sim about a dive bar on a shabby space station. Early days: ships dock, crews spend money at the bar, and miners and Combine auditors get into fights if seated too close.

Tap the floor to place or remove a crate, and people route around it.

```sh
npm ci
npm run dev -- --host
```
